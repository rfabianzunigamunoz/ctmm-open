# Historial de cambios

## 0.1.0 - 2026-09-21

### Añadido

- estructura inicial de CTMM Open;
- documentación de CTMM Core 1.0;
- archivos de citación, contribución, gobernanza y versionamiento;
- separación entre núcleo, extensión universitaria, CTMM+IA y CTMM-DS;
- plantillas para reportar casos y proponer indicadores.

### Pendiente

- aprobación formal de autores y titulares;
- licencia pública definitiva;
- DOI y URL oficial;
- normalización de fórmulas de los instrumentos;
- publicación de instrumentos depurados.
