# Contribuir a CTMM Open

CTMM Open recibe contribuciones que fortalezcan la claridad, aplicabilidad y evidencia del modelo sin alterar su núcleo de manera informal.

## Formas de contribuir

- reportar una ambigüedad o error;
- proponer un indicador contextualizado;
- aportar una rúbrica o lista de cotejo;
- documentar un caso de aplicación;
- proponer una mejora conceptual;
- contribuir código a herramientas CTMM.

## Información mínima

Toda propuesta debe incluir:

1. problema o necesidad;
2. nivel educativo y asignatura;
3. actividad evaluada;
4. habilidad y nivel CTMM relacionados;
5. indicador y evidencia observable;
6. instrumento o procedimiento aplicado;
7. resultados, dificultades y limitaciones;
8. cambios frente a CTMM Core o al instrumento original.

## Clasificación de propuestas

| Tipo | Alcance | Ejemplo |
|---|---|---|
| Corrección | No cambia el significado | Error ortográfico |
| Indicador contextual | Conserva habilidad y nivel | Descriptor para árboles AVL |
| Instrumento | Nueva forma de registro | Rúbrica para programación |
| Extensión | Añade una dimensión o contexto | Ética en actividades con IA |
| Cambio del núcleo | Modifica conceptos centrales | Nueva habilidad oficial |

## Revisión

Las propuestas se valorarán por coherencia teórica, claridad, observabilidad, trazabilidad, aplicabilidad y evidencia de uso. Un aporte puede aprobarse, solicitar ajustes, mantenerse como experimental o rechazarse con justificación.

## Datos y ética

No incluya nombres, identificadores ni producciones estudiantiles que permitan reconocer a una persona sin autorización. Los datos deben estar anonimizados y contar con las condiciones éticas y legales correspondientes.

## Licencia de las contribuciones

Al contribuir, la persona confirma que puede compartir el material y acepta que la documentación original se distribuya bajo CC BY-SA 4.0 y el código bajo Apache License 2.0, una vez formalizadas estas licencias por el proyecto.
