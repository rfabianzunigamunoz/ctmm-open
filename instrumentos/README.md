# Instrumentos CTMM

Esta carpeta alojará versiones depuradas y citable de:

- formato individual de tres niveles;
- planilla grupal inicial y final;
- formato individual de métricas GQM;
- planilla grupal de métricas;
- autoevaluaciones;
- rúbricas y listas de cotejo por contexto.

Antes de publicar un instrumento se debe:

1. eliminar datos identificables y datos de ejemplo no necesarios;
2. verificar fórmulas y compatibilidad;
3. documentar la regla de nivel;
4. indicar versión, autores y licencia;
5. incluir instrucciones y un ejemplo anonimizado.
